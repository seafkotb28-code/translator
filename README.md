# PDF Translator 🌐

برنامج ترجمة فورية للنصوص الإنجليزية في ملفات PDF والمواقع.

## ✨ المميزات

- 🌍 ترجمة فورية عند نسخ أي نص (Ctrl+C)
- ⚡ اختصار سريع لترجمة النص المحدد (Ctrl+Alt+T)
- 🔊 نطق الكلمات الإنجليزية (زر استمع)
- 🌙 تصميم Dark Mode عصري
- 📦 يعمل كملف exe بدون الحاجة لتثبيت Python

## 🛠️ التقنيات

- Python 3.12
- googletrans (الترجمة)
- pyttsx3 (النطق)
- tkinter (الواجهة)
- pyperclip (الحافظة)
- keyboard (الاختصارات)

## 📦 التثبيت

```bash
pip install pyperclip keyboard googletrans==4.0.0rc1 pyttsx3
